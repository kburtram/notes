- **Tab order:** `Results | Messages | Vector | Query Plan`. Results is the only tab allowed before Messages; all contributed result tabs follow Messages. Every Vector mockup's older tab strip is non-normative.

## Non-negotiables (apply to every checkpoint)

- **Privacy**: no cell values, vectors, coordinates, SQL text, keys, labels, model outputs, or projection coordinates in telemetry/diag/markers/errors. Counts/bytes/ms/enums only. Canary tests required.
- **Wire**: typed cells use `data`/`wkb` field, never `v` (generic `{$t,v}` wrapper collision — verified). Opt-in negotiation only (capability + per-execute option); never emit tags to non-opted clients.
- **Webview**: zero network requests (per-surface CSP `default-src 'none'`); no DDL execution ever; no model call without host-minted confirmation; webview has zero authority over budgets/store/run/lease IDs.
- **Budgets host-authoritative** in QueryTuning registry: 25k rows scanned / 5k sample / 8M components / 64 MiB packed input; RPC 1 MiB soft / 2 MiB hard / 32 MiB session; ≤2 workers, ≤2 aux sessions; K 20 default / 1000 max; disclosed scan-bytes budget on `VectorSampleDescriptor` (DA A6) so perftest can assert it.
- **Unopened cost ≈ 0**: `appliesTo` sniff (from `QsResultColumn.sqlType`) in entry chunk; everything else behind `import()` on first tab activation; no worker/session/scan until opened; bundle-budget test stays green; QS boot phase numbers must not regress (r11: editorInteractive ~497ms, resultsRendered ~776ms in the d796deba baseline run).
- **Evidence honesty** (RR P0s): every displayed fact carries `VectorEvidenceSource`; findings carry `VectorFindingSubject`; timing labeled "single observation" unless repeated; analyzed vs rendered counts separate; frozen query vector per comparison; exclusion policy shared exact/approx; read consistency declared; DB-scoped model names (never schema-qualified); layered network claims; index state machine before scripts.
- **Markers registry-first**: add names to `perftest/packages/observability-contracts/src/registry/event-types.json` → build/test/generate → copy generated TS to `vscode-mssql/extensions/mssql/src/sharedInterfaces/observabilityContract.generated.ts`. Balanced begin/end; explicit `traceId` for stitched waterfalls (QS markers are trace-orphans today — r10).
- **Feature gates**: `mssql.queryStudio.vectorWorkbench.enabled` (default off), later `mssql.queryStudio.spatial.enabled` (default off). Vector wire negotiation only when gate on.
- **Commits**: sqltoolsservice `STS2: …`; vscode-mssql `qs: vector — …` / `qs: spatial — …`; perftest `core: …`. Vector phase fully committed before spatial begins.
- **Localization**: every visible string via l10n from first patch. Fluent + codicons + VS Code tokens; radius ≤2px; no cards/chips/tinted headers (DA U1–U10 house style; r01/r06 have exact numbers).

## Locked architecture (vector)

SqlDataReader → STS2 SqlClient driver (`SqlClientVectorValueReader`) → `DriverVectorValue` → `WireValueEncoder` vector tag → ordinary compact pages → `sts2Backend` normalization → RowStore/RetainedRowStore → controller-bound `VectorResultSource` → sparse scan (reason `vectorAnalysis`, non-admitting) → packed `Float32Array` (transferred) → Node `worker_threads` `vectorAnalysisWorker` (float64 accumulation; PCA = covariance-free orthogonal iteration) → opaque pull RPC (derived data only) → webview.

Forbidden: second raw cache; feature-specific result stream; webview loop over `qs/getRows`; provider CLR types past the driver; webview-supplied IDs.

Cell: `{$t:"vector", version:1, status:"ok", dimensions, baseType:"float32", encoding:"f32le", byteLength, data:<base64 LE>}`; `byteLength === dimensions*4`; never truncate — unavailable sentinel with reason enum instead. Compact type hint `vector:f32le:v1` (lockstep both sides). Float16 = honest `textFallback`. Column metadata additive fields (`length` etc.) give dims = (ColumnSize − 8)/4.
